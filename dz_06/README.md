Транспортный уровень—отвечает за передачу данных между приложениями на разных компьютерах
TCP и UDP-два основных протокола транспортного уровня
Сегментация—разделение больших данных на небольшие части для передачи по сети
Порт-номер, который помогает определить, какому приложению предназначены данные
Сокет-сочетание IP адреса и порта, используемое для сетевого обмена
UDP-быстрый протокол, который передаёт данные без установления соединения и не гарантирует их доставку
UDP используется в DNS, DHCP, TFTP и SNMP
TCP-надёжный протокол, который обеспечивает доставку данных в правильном порядке
TCP устанавливает соединение в три этапа: SYN → SYN-ACK → ACK
Надёжность TCP обеспечивается подтверждениями ACK, повторной отправкой потерянных данных и механизмом скользящего окна который регулирует скорость передачи
